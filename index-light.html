Architecture

전체 구조도

연구자의 오더가 팀장 서달미를 거쳐 9개 에이전트로 분배되고, 각 에이전트가 담당 기능을 수행한 뒤 검증을 거쳐 다시 연구자에게 돌아옵니다.

Overview

어떻게 동작하나

연구책임자(사람)가 오더를 남기면, 서달미가 받아 담당 에이전트로 라우팅하고, 산출물은 공유 레지스트리를 거쳐 다음 단계로 흐릅니다.

🧭

오케스트레이션

서달미가 오더를 태스크로 분해하고, 담당·순서를 정해 병렬/순차로 배정한 뒤 품질을 검증합니다.

💬

KOTI TALK 메신저

채널·태스크 보드·에이전트 상태를 실시간으로 보여줍니다. 오더창에 지시를 넣으면 바로 처리됩니다.

🔗

산출물 핸드오프

에이전트는 서로 직접 호출하지 않고, 공유 레지스트리 + 서달미 중재로 산출물을 주고받습니다.

Get Started

시작하기

GitHub를 몰라도 괜찮아요. 압축파일(.zip)을 받아 Claude에게 건네주면 알아서 설치·실행합니다.

🚀 가장 쉬운 방법 — 다운로드해서 Claude에게 맡기기

STEP 1
ZIP 내려받기
아래 버튼으로 압축파일(.zip) 다운로드
→
STEP 2
압축 풀기
받은 zip을 더블클릭해 폴더로 풀기
→
STEP 3
Claude에게 전달
그 폴더를 열어주고 "설치하고 KOTI TALK 실행해줘"라고 요청
⬇ ZIP 파일 다운로드

버튼이 안 열리면: GitHub 저장소 페이지에서 초록색 Code 버튼 → Download ZIP.

🖥 KOTI TALK 런처 — 버튼 ①→⑥ 순서로 누르기

launch.bat을 실행하면 런처 창이 뜹니다. 위에서부터 순서대로 누르면 돼요.

1
의존성 설치 — requirements.txt 패키지 설치 (처음 1회만)
2
스킬 설치 — 에이전트가 쓰는 스킬 내려받기 (처음 1회만)
3
메신저 서버 시작 — 로컬 서버 기동 (localhost:8000)
4
메신저 열기 — 브라우저에서 KOTI TALK 화면 열기
5
Claude Code 시작 — 새 콘솔에서 claude 실행 → 팀장 서달미로 동작
6
서버 정지 — 끝낼 때 실행 중인 서버 종료

💡 처음 1회만 ①②까지 누르고, 그 다음부터는 ③ → ④ → ⑤만 누르면 됩니다. 끝낼 땐 ⑥ 서버 정지. ④에서 열린 KOTI TALK 화면 하단 오더창에 지시를 넣으면 팀장 서달미가 알아서 담당 에이전트에게 분배합니다.

직접 설치하기 (개발자용 · 3단계)

01

클론 & 설치

# 저장소 클론
git clone https://github.com/yewon918/KOTI_multi-agent.git
cd KOTI_multi-agent

# 파이썬 의존성 (3.10+)
pip install -r requirements.txt
02

환경 설정

# .env 만들고 본인 경로 입력
copy .env.example .env

# (선택) 외부 스킬 설치
python scripts/install_skills.py
03

KOTI TALK 실행

# Windows
launch.bat
# mac / Linux
./launch.command

# → http://localhost:8000 열림
실행 후 레포 루트에서 Claude Code를 켜면 그 세션이 팀장 서달미로 동작합니다. KOTI TALK 오더창에 지시를 넣어보세요 — 예: "탄소중립 교통정책 최신 동향 정리해줘" (차은수) · "위키만 근거로 리뷰 원고 써줘" (서지원).

🛠 자기 과제에 맞추기

.env 경로 → CLAUDE.md 라우팅 수정 → .claude/agents/에 에이전트 추가/변경. 설계 스펙은 설계/에 함께 둡니다.

🔒 공유되지 않는 것

workspace/(산출물) · comms/(로그) · .env(개인 경로) · skills/(외부). 클론하면 프레임워크만 받고 각자 채웁니다.
